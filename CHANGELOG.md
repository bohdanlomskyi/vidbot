# История изменений

## 1.1.0 — 2026-11-07

### Добавлено

- **Плеер в чате.** После `/play` под сообщением появляется панель с обложкой, названием-ссылкой, полосой времени и кнопками: ⏮ Назад, ⏸ Пауза / ▶ Продолжить, ⏭ Далее, ⏹ Стоп, 📋 Очередь, 🔀 Перемешать, 🔁 Повтор, ⭐ В избранное, 🔉 и 🔊. Панель появляется в том канале, где пользуются ботом, и при новом треке переезжает вниз чата. `/nowplaying` переносит её вручную, `/setup` закрепляет канал.
- **Поиск YouTube.** `/play название` и `/search` показывают 5 вариантов с каналом и длиной, выбор одной кнопкой.
- **Свои файлы.** Поле `file` в `/play`: mp3, wav, flac, ogg, m4a и другие. Файл проверяется, сохраняется в `music/uploads` и сразу играет. Файлы, скопированные в папку `music`, находятся без перезапуска. Новый `music.cmd` открывает папку.
- **Сообщения о действиях.** Бот пишет в чат о паузе, пропуске, остановке, громкости, повторе, перемешивании, перемещении, отключении по таймеру, потере связи, том, что его выгнали из канала, ошибках треков и конце очереди. Уровень: `/settings announce` (всё, важное, ничего).
- Из анализа других ботов: избранное `/favorites` и кнопка ⭐, `/previous`, `/skipto`, `/play next:True`, режим 24/7 `/settings stay-247`.
- Настройки `UPLOADS_ENABLED`, `UPLOAD_MAX_MB`, `UPLOAD_QUOTA_MB`.

### Ускорено

- Запуск трека YouTube по ссылке: один процесс yt-dlp вместо двух (метаданные и звук приходят из одного запуска). Выбор из результатов поиска не делает лишнего запроса. Ожидаемый выигрыш — одна из двух задержек разбора страницы (около 3,5 с каждая в замере); сквозной замер невозможен из среды разработки.

### Исправлено

- `update.cmd` для установки из ZIP не находил обновление, пока на `main` нет установщика.
- Ответы и ошибки установщика и документации приведены в соответствие с тем, что реально проверено.

### Что делать после обновления

Запустите `update.cmd` (или `git pull`, затем `npm run build` и `npm run commands:register`): новые команды появятся в Discord. База обновится сама (миграция 4: избранное и новые настройки).

### Не проверено

Работа в настоящем голосовом канале Discord, кнопки и публичные сообщения в настоящем клиенте, запуск настоящих видео YouTube, Windows.
