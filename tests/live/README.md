# Живые тесты

Живые тесты обращаются к настоящему Discord. По умолчанию они пропускаются, и обычный запуск
`npm test` их не выполняет. Запускаются они отдельно:

```bash
MELODY_LIVE_TESTS=1 DISCORD_TOKEN=... DISCORD_GUILD_ID=... npm run test:live
```

Переменные:

- `MELODY_LIVE_TESTS=1` включает тесты. Без него они пропускаются.
- `DISCORD_TOKEN` — токен тестового бота. Используйте отдельное тестовое приложение, а не боевое.
- `DISCORD_GUILD_ID` — тестовый сервер, на котором бот уже приглашён.
- `MELODY_LIVE_VOICE_CHANNEL_ID` — голосовой канал на этом сервере. Нужен для проверки подключения к голосу
  и обмена ключами DAVE. Без него проверка голоса пропускается.

Тесты не выводят токен. Не сохраняйте токен в репозитории и не запускайте живые тесты в общедоступном CI.
