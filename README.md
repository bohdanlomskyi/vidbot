# Melody — музыкальный бот для Discord

Melody воспроизводит музыку в голосовых каналах Discord. Источники: локальная библиотека оператора, каталог разрешённых потоков и, по желанию и экспериментально, YouTube. Бот написан на TypeScript поверх discord.js 14 и @discordjs/voice. Шифрование голоса выполняет библиотека DAVE, кодирование Opus — @discordjs/opus в отдельном потоке, чтобы не нагружать поток, который обрабатывает команды.

> **Статус проверки.** Типы, линтер, тесты, сборка, диагностика, запуск бота с заведомо неверным токеном и сканирование библиотеки проверены локально. Не проверено: живое голосовое подключение с DAVE, YouTube, сборка Docker-образа (в среде разработки не было Docker-демона), Windows и macOS. Подробности — в [docs/deployment.md](docs/deployment.md) и [docs/architecture.md](docs/architecture.md).

## Возможности

- **Плеер в чате, как у популярных ботов.** После `/play` под сообщением появляется панель: обложка, название-ссылка, полоса времени, очередь, громкость и кнопки ⏮ Назад · ⏸ Пауза · ⏭ Далее · ⏹ Стоп · 📋 Очередь · 🔀 Перемешать · 🔁 Повтор · ⭐ В избранное · 🔉 / 🔊. Панель появляется в том канале, где вы пользуетесь ботом, и при каждом новом треке переезжает вниз чата. Закрепить её в одном канале можно командой `/setup`.
- **Поиск по названию.** `/play lord verity` ищет на YouTube и показывает 5 вариантов с каналом и длиной; нажмите номер. Ссылку YouTube можно вставить сразу. Работает, если включён YouTube.
- **Свои файлы.** Перетащите mp3, wav, flac, ogg или m4a в поле `file` команды `/play`, или просто положите их в папку `music` (на Windows откроет `music.cmd`). Подробности — в разделе «Своя музыка».
- **Бот пишет в чат обо всём, что делает:** пауза, пропуск, громкость, отключение по таймеру, «меня выгнали из канала», потеря связи, ошибки треков. Уровень настраивается: `/settings announce` — всё, только важное или ничего.
- Избранное у каждого участника (`/favorites`), `/previous`, `/skipto`, `/play next:True`, режим 24/7 (`/settings stay-247`).
- Независимые сессии на каждом сервере: очередь, текущий трек и состояние не пересекаются.
- Автоматический выход из канала: после `IDLE_TIMEOUT_SEC` без воспроизведения или после `EMPTY_CHANNEL_TIMEOUT_SEC`, если в канале никого нет (кроме режима 24/7).
- Права: участники голосового канала управляют воспроизведением, DJ-роль и администраторы получают расширенные команды. Голосование за пропуск выключено по умолчанию.

## Установка на Windows: 3 шага, около 5 минут

Ничего заранее ставить не нужно: ни Node.js, ни FFmpeg, ни Python, ни права администратора. Установщик скачает всё сам в папку бота и проверит контрольные суммы файлов.

### Шаг 1. Создайте бота в Discord (2 минуты)

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) → **New Application** → введите имя → **Create**.
2. Слева **Bot** → **Reset Token** → **Yes, do it!** → **Copy**. Это токен — пароль бота. Пока просто держите его в буфере обмена, никому не отправляйте и не показывайте на скриншотах.

Больше на портале ничего делать не нужно: Client ID, ссылку-приглашение и сервер установщик определит сам.

### Шаг 2. Скачайте и установите Melody

**Вариант А — одной командой.** Нажмите **Пуск**, введите `PowerShell`, откройте его и вставьте:

```powershell
irm https://raw.githubusercontent.com/bohdanlomskyi/vidbot/claude/quirky-brahmagupta-lz9mjn/scripts/windows/bootstrap.ps1 | iex
```

Бот скачается в папку `C:\Users\<вы>\Melody`, и установка начнётся сама.

**Вариант Б — архивом.**

1. Скачайте [Melody.zip](https://github.com/bohdanlomskyi/vidbot/archive/refs/heads/claude/quirky-brahmagupta-lz9mjn.zip).
2. Правой кнопкой по архиву → **Извлечь всё…** → выберите папку, например `C:\Melody`.
3. В распакованной папке дважды щёлкните **`install.cmd`**. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите **Подробнее** → **Выполнить в любом случае**.

### Шаг 3. Ответьте на вопросы установщика

Установщик сделает всё по порядку и спросит только то, что не может узнать сам:

Потом в Discord:

1. Напишите на сервере **`/setup`** и выберите текстовый канал — там появится панель с кнопками.
2. Зайдите в голосовой канал и напишите **`/play test-tone`** — прозвучит проверочный сигнал. Значит, всё работает.
3. Добавьте свою музыку — два способа, оба описаны в разделе «Своя музыка» ниже: перетащите файл в команду `/play` или положите его в папку `music` (её открывает `music.cmd`). Если YouTube включён, в `/play` можно просто написать название.

## Установка на Linux и macOS

Нужны Node.js 24.17 или новее (например, `nvm install 24`) и FFmpeg (`sudo apt install ffmpeg` или `brew install ffmpeg`). Затем:

```bash
git clone -b claude/quirky-brahmagupta-lz9mjn https://github.com/bohdanlomskyi/vidbot.git melody
```

```bash
cd melody && ./install.sh
```

`install.sh` установит пакеты, соберёт бота и запустит тот же мастер настройки, что и на Windows. Запуск — `./start.sh`, повторная настройка — `npm run setup`. yt-dlp для YouTube мастер скачает сам. Для сервера, который работает круглосуточно, удобнее Docker (раздел ниже).

## Ручная установка (для тех, кто хочет всё контролировать)

Требования: Node.js 24.17 или новее (проверено на 24.22.2, версия в `.nvmrc`), FFmpeg с `ffprobe` (проверено на 6.1.1 и 9.0.2).

```bash
npm ci
cp .env.example .env
# Заполните DISCORD_TOKEN и DISCORD_CLIENT_ID в .env, либо выполните npm run setup
npm run build
npm run doctor
npm run commands:register
npm start
```

В Windows вместо `npm ci` выполните `npm.cmd ci --ignore-scripts`, затем `npm.cmd rebuild @discordjs/opus`: так не нужны Python и компилятор. Вместо `cp` — `copy`. Если PowerShell пишет, что выполнение сценариев отключено, используйте `npm.cmd` вместо `npm`. Для разработки — `npm run dev`.

### Настройки приложения в Discord

- **Privileged Gateway Intents** оставьте выключенными. Melody использует только `Guilds` и `GuildVoiceStates` и не читает сообщения.
- По желанию отключите **Public Bot**, чтобы приглашать бота мог только владелец приложения.
- Client ID — **General Information** → **Application ID**. Мастер настройки берёт его по токену сам, поэтому команды всегда относятся к тому же боту, что и токен.

### Права и приглашение

Melody запрашивает только необходимые права:

- **View Channels**, **Send Messages**, **Embed Links** — для панели управления;
- **Connect**, **Speak** — для голоса;
- **Manage Channels** — для кнопки «создать канал» в `/setup`.

Права Administrator бот не запрашивает и не использует. Мастер настройки открывает такую ссылку сам. Вручную подставьте свой Client ID:

```text
https://discord.com/oauth2/authorize?client_id=ВАШ_CLIENT_ID&scope=bot+applications.commands&permissions=3165200
```

Без Manage Channels используйте `permissions=3165184`.

## Настройка сервера

1. Пригласите бота и зарегистрируйте команды (раздел ниже).
2. Администратор сервера выполняет `/setup`, выбирает текстовый канал, и бот публикует там панель управления.
3. По желанию настройте `/settings` (см. таблицу ниже).

## Регистрация команд

```bash
npm run commands:register              # на сервере из DISCORD_GUILD_ID, если он задан
npm run commands:register -- --global  # глобально, даже если DISCORD_GUILD_ID задан
```

Серверные команды появляются сразу. Глобальные могут появиться в течение часа. Повторный запуск безопасен: набор команд заменяется целиком.

В Docker: `docker compose run --rm bot node dist/scripts/register-commands.js`.

Успешные действия бот объявляет в чате коротким сообщением с именем того, кто их выполнил. Ошибки и подсказки видны только вам.

| Подкоманда       | Значение                  | Смысл                                                                                                                     |

| `idle-timeout`   | секунды, 10–3600          | Выход из канала после паузы без воспроизведения                                                                           |

| `queue-limit`    | 1–500                     | Максимум треков в очереди                                                                                                 |

## Права доступа

Слушатель — участник голосового канала, в котором находится бот. DJ — участник с ролью из `/settings dj-role`. Администратор — участник с правом Manage Server или Administrator.

| Действие                                                                        | Кто может                                                                                                                                                                                                      |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Просмотр: `/queue`, `/nowplaying`, `/history`, `/status`, `/help`               | все                                                                                                                                                                                                            |
| Добавление: `/play`, `/playlist`, `/replay`, `/join`                            | любой в голосовом канале. Если бот занят в другом канале, он туда не переходит                                                                                                                                 |
| Пауза, продолжение, пропуск, перезапуск трека, перемешивание, повтор, громкость | при политике `everyone` — любой слушатель; при политике `dj` — только DJ и администраторы. Обычный слушатель при включённом голосовании пропускает трек только голосами, если в канале больше одного слушателя |
| Удаление трека (`/remove`)                                                      | DJ и администраторы; единственный слушатель при политике `everyone`; иначе только тот, кто добавил трек                                                                                                        |
| Очистка, остановка, отключение (`/clear`, `/stop`, `/leave`)                    | DJ и администраторы; единственный слушатель при политике `everyone`                                                                                                                                            |
| Перенос бота (`/move`)                                                          | DJ и администраторы                                                                                                                                                                                            |
| Настройки (`/setup`, `/settings`)                                               | администраторы                                                                                                                                                                                                 |

Ограничения по выбору источников и длительности действуют для всех пользователей, включая администраторов.

## Музыка

### Своя музыка

Два способа, оба без перезапуска бота.

1. **Через Discord.** В команде `/play` нажмите на поле **`file`** и выберите файл (или перетащите его в окно ввода). Бот скачает файл, проверит, что это аудио, сохранит его в `music/uploads` и сразу включит. Повторная загрузка того же файла не создаёт копию. Ограничения (меняются в `.env`): `UPLOAD_MAX_MB` — размер одного файла, по умолчанию 25 МБ (Discord сам не даёт прикрепить больше своего лимита); `UPLOAD_QUOTA_MB` — всего в `music/uploads`, по умолчанию 2000 МБ; `UPLOADS_ENABLED=false` отключает загрузку. Файл не принимается, если это не аудио, даже с расширением `.mp3`.
2. **Через папку.** Скопируйте файлы в `music` (на Windows её открывает `music.cmd`). Если `/play название` ничего не нашёл, бот один раз пересканирует папку и повторит поиск, так что новый файл находится сразу.

Загруженные и скопированные файлы одинаково находятся по названию: начните писать в `/play`, и появятся подсказки.

### Локальная библиотека

- Положите файлы в каталог `MUSIC_DIR` (по умолчанию `music/`). Форматы: mp3, flac, wav, ogg, oga, opus, m4a, aac.
- Каталог сканируется при запуске и затем каждые `MUSIC_RESCAN_MINUTES` минут. Значение 0 отключает пересканирование. Вручную: `npm run library:scan`.
- В `/play` начните вводить название: подсказки покажут треки из библиотеки. Если название треку из библиотеки совпадает точно, он включается сразу, иначе (при включённом YouTube) начинается поиск на YouTube.
- Тестовый тон для проверки звука: `npm run library:tone`. Файл создаёт FFmpeg, прав на него не нужно.

Подробнее: [music/README.md](music/README.md).

### Потоковые источники (выключены по умолчанию)

Включите `STREAM_PROVIDER_ENABLED=true` и заполните каталог `STREAM_CATALOG_FILE` (по умолчанию `config/streams.json`). Пример: [config/streams.example.json](config/streams.example.json).

Каждая запись каталога:

- `id` — строчные латинские буквы, цифры и дефис, 3–40 символов, не начинается с `lib-`;
- `title` — название, до 100 символов; `artist` — необязательно, до 100 символов;
- `url` — адрес `https`. `http` допускается только с `allowHttp: true`;
- `allowedHosts`, `allowedPorts` — необязательные ограничения хоста и порта;
- `live` — `true` для прямого эфира: тогда лимит байт не применяется;
- `durationSec`, `thumbnailUrl` — необязательные поля.

Адреса проверяются перед подключением: нельзя учётные данные в адресе, нельзя локальные и служебные адреса, каждое перенаправление проверяется заново. Пользователи выбирают поток только по идентификатору, адрес потока им не показывается и в журнал не попадает.

### YouTube (экспериментально, выключен по умолчанию)

Модуль выключен, пока оператор не включит `YOUTUBE_PROVIDER_ENABLED=true` (проще всего — ответить «д» в мастере настройки: он сам скачает yt-dlp и разрешит YouTube на сервере). Для работы нужна программа yt-dlp. Перед включением прочитайте [docs/youtube.md](docs/youtube.md): условия YouTube ограничивают автоматизированный доступ и загрузку контента. Включайте модуль только при наличии письменного разрешения YouTube и правообладателей.

## Docker

```bash
cp .env.example .env          # заполните токен и Client ID
docker compose up -d --build
docker compose logs -f bot
docker compose ps             # статус healthy означает, что бот готов
```

Что делает `compose.yaml`:

- переменные окружения читаются из `.env` во время запуска и не запекаются в образ;
- корневая файловая система только для чтения, все capabilities сняты, включён `no-new-privileges`;
- каталоги `music/` и `config/` смонтированы только для чтения, база и служебные файлы лежат в томе `melody-data`;
- входящие порты не публикуются: бот только подключается к Discord.

Команды для обслуживания в контейнере:

```bash
docker compose run --rm bot node dist/scripts/register-commands.js
docker compose run --rm bot node dist/scripts/doctor.js
docker compose run --rm bot node dist/scripts/scan-library.js
```

Сборка образа не выполнялась в этой среде: в ней не было Docker-демона. Файлы Docker проверены статически тестами и командой `docker compose config`. Подробнее: [docs/deployment.md](docs/deployment.md).

## Диагностика

- `npm run doctor` проверяет Node.js, конфигурацию, FFmpeg и ffprobe, каталоги, базу данных, Opus, DAVE и шифрование, при необходимости yt-dlp и каталог потоков. Токен показывается только как «задан (скрыт)». Код возврата 1 означает ошибку хотя бы в одной проверке.
- `node dist/scripts/healthcheck.js` — проверка для Docker: бот должен быть готов, а файл состояния обновлён не более 90 секунд назад.
- `/status` в Discord показывает состояние базы, FFmpeg, библиотеки, потоков и YouTube.

## Ограничения

- Очередь, текущий трек и громкость сессии хранятся в памяти процесса. После перезапуска очередь не восстанавливается.
- `/volume` действует до перезапуска. Постоянную громкость сервера задаёт `/settings default-volume`.
- Бот рассчитан на один процесс. Горизонтальное масштабирование не поддерживается.
- Не проверено на живом Discord: голосовое подключение с DAVE и воспроизведение в настоящем канале. Для этого есть живые тесты (см. [tests/live/README.md](tests/live/README.md)).
- YouTube проверен частично: реальный поиск (`ytsearch`) выполнялся и вернул результаты, а разбор страницы видео и воспроизведение из среды разработки недоступны (YouTube требует подтверждения, что вы не бот, для адресов дата-центров). Запуск по ссылке, быстрый старт одним процессом yt-dlp и выбор из результатов поиска проверены на поддельном yt-dlp, а не на настоящем YouTube.
- Кнопки панели, публичные сообщения о действиях, перенос панели и загрузка файлов через вложение проверены тестами с подменой Discord, но не в настоящем клиенте Discord.
- Windows и macOS не проверялись в среде разработки. Скрипты установки для Windows проверены только статическими тестами (кодировка, окончания строк, ссылки между файлами) и чтением кода; они ни разу не запускались на Windows и не разбирались PowerShell. Установщик на Linux не запускался целиком, только `start.sh`.

## Обслуживание

- **Журнал.** Записи в формате JSON в стандартный вывод. Токен и другие секреты маскируются.
- **Резервная копия.** Остановите бота и сохраните каталог `data/` (в Docker — том `melody-data`). Там лежит база SQLite.
- **Обновление.** В Windows — `update.cmd`. Вручную: `git pull`, затем `npm ci`, `npm run build`, `npm run commands:register` и перезапуск.
- **Смена токена.** Сбросьте токен в Developer Portal и запустите `setup.cmd` (или `npm run setup`). Старый токен перестанет работать.

## Работа с секретами

- `.env` добавлен в `.gitignore`. Не коммитьте его и не вставляйте токен в чаты, задачи или логи.
- Токен не печатается ни в журнал, ни в диагностику, ни в результаты тестов.
- Образ Docker не содержит секретов. `.env` передаётся при запуске контейнера.
- Если токен утёк, сбросьте его немедленно.
