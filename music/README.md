# Музыкальная библиотека

Сюда кладут аудиофайлы, которые бот воспроизводит командой `/play`. Содержимое этого каталога
не попадает в репозиторий: в `.gitignore` указано игнорировать всё, кроме этого файла и `.gitkeep`.

## Что можно класть

- Форматы: `mp3`, `flac`, `wav`, `ogg`, `oga`, `opus`, `m4a`, `aac`.
- Подкаталоги поддерживаются до пяти уровней вложенности.
- Скрытые файлы и каталоги (начинающиеся с точки) пропускаются.
- Символические ссылки пропускаются: бот не читает файлы за пределами каталога.
- Имена с небезопасными символами пропускаются.
- Не больше 5000 файлов за одно сканирование.

Добавляйте только музыку, на использование которой у вас есть права: собственные записи, музыку
с лицензией, которая разрешает такое использование, или материалы, переданные правообладателем.

## Как обновить каталог

- Сканирование выполняется при запуске бота и затем каждые `MUSIC_RESCAN_MINUTES` минут.
- Вручную: `npm run library:scan`. В Docker: `docker compose run --rm bot node dist/scripts/scan-library.js`.
- Изменившиеся файлы определяются по размеру и времени изменения. Их длительность проверяется через `ffprobe`.

## Тестовый тон

Команда `npm run library:tone` создаёт `music/examples/test-tone.wav`: десять секунд синусоиды
440 Гц. Файл синтезирует FFmpeg, поэтому прав на него не требуется. Существующий файл не перезаписывается.
