# Источники музыки

Melody воспроизводит только то, что оператор явно подключил. Есть три типа источников.

| Источник                       | Как попадает в очередь                                      | Как включить                    | Кто отвечает за права                  |
| ------------------------------ | ----------------------------------------------------------- | ------------------------------- | -------------------------------------- |
| Локальная библиотека (`local`) | файл из каталога `MUSIC_DIR`, идентификатор вида `lib-…`    | включена всегда                 | оператор                               |
| Потоки (`stream`)              | запись каталога `STREAM_CATALOG_FILE`, идентификатор записи | `STREAM_PROVIDER_ENABLED=true`  | оператор, выбравший потоки             |
| YouTube (`youtube`)            | ссылка на видео или плейлист                                | `YOUTUBE_PROVIDER_ENABLED=true` | оператор; см. [youtube.md](youtube.md) |

## Права и ответственность

- Melody не содержит музыки и не выдаёт прав. Оператор отвечает за всё, что добавлено в библиотеку, в каталог потоков и что разрешено на сервере.
- Для локальной библиотеки подходят собственные записи, музыка с лицензией, которая разрешает такое использование, и материалы, переданные правообладателем. Проверяйте условия конкретной лицензии. Сама по себе запись «свободная музыка» не означает разрешения на любое использование.
- Для потоков включайте только те, на вещание которых у вас есть право. Проверяйте условия провайдера потока.
- Для YouTube условия сервиса ограничивают автоматизированный доступ и загрузку контента. Модуль выключен по умолчанию. Подробности — в [youtube.md](youtube.md).

## Что бот хранит

В базе данных SQLite (`DATABASE_PATH`):

- **Настройки сервера:** канал панели, идентификатор сообщения панели, роль DJ, политика управления, лимиты, громкость по умолчанию, процент голосования, разрешённые источники.
- **История воспроизведения:** название, исполнитель, тип источника, идентификатор источника, идентификатор пользователя, добавившего трек, время начала воспроизведения. Хранится до 200 последних записей на сервер. Для потоков сохраняется идентификатор записи каталога, а не адрес потока. Для библиотеки сохраняется идентификатор `lib-…`.
- **Каталог библиотеки:** относительный путь внутри `MUSIC_DIR`, название, исполнитель, длительность, размер и время изменения файла. Сами аудиофайлы в базу не копируются.

Что бот не хранит:

- Адреса потоков: они берутся из каталога и живут только в памяти процесса. В базу и журнал не пишутся.
- Аудио с YouTube: звук передаётся по конвейеру в FFmpeg и на диск не сохраняется.
- Токен Discord: он не записывается ни в базу, ни в журнал.

## Локальная библиотека

- Форматы: mp3, flac, wav, ogg, oga, opus, m4a, aac.
- Скрытые файлы и каталоги (начинаются с точки) пропускаются.
- Символические ссылки пропускаются, поэтому бот не читает файлы за пределами `MUSIC_DIR`.
- Имена с небезопасными символами пропускаются.
- Глубина вложенности до пяти уровней. Не больше 5000 файлов за одно сканирование.
- Длительность определяется через `ffprobe`. Повторно проверяются только файлы с изменившимся размером или временем изменения.

Идентификатор трека вычисляется из относительного пути. Если файл переименовать или переместить, его идентификатор меняется, и старые ссылки на него перестают работать.

## Каталог потоков

Файл `config/streams.json` (пример — `config/streams.example.json`) описывает разрешённые потоки. Каждая запись проверяется отдельно: одна ошибка не отключает остальные записи. Ошибки выводятся оператору в виде текста, который называет запись, но не показывает адрес.

Правила:

- идентификаторы уникальны; повторный идентификатор пропускается с сообщением;
- адрес только `https`, если не указано `allowHttp: true`;
- адрес не содержит логина и пароля;
- адрес не указывает на локальную, закрытую или служебную сеть;
- если задан `allowedHosts`, хост адреса должен входить в список;
- если задан `allowedPorts`, порт адреса должен входить в список;
- конечные потоки ограничены `STREAM_MAX_BYTES`; прямые эфиры (`live: true`) лимита байт не имеют, но их молчание ограничено таймаутом.

Проверить каталог можно командой `npm run doctor`: строка «Каталог потоков» покажет число записей и отклонённые записи.

## Добавление своей музыки

1. Скопируйте файлы в `MUSIC_DIR` (по умолчанию `music/`).
2. Запустите `npm run library:scan` или дождитесь автоматического сканирования.
3. Проверьте в Discord: `/play` с началом названия покажет подсказки.

## Ограничения воспроизведения

Лимиты действуют для всех источников:

- длительность одного трека: `MAX_TRACK_DURATION_SEC` (по умолчанию 0 — без ограничения), для сервера — `/settings max-duration` (0 минут — без ограничения);
- длина очереди: `MAX_QUEUE_SIZE` (по умолчанию 100), для сервера — `/settings queue-limit`;
- частота команд: `RATE_LIMIT_PER_10S` (по умолчанию 6 команд за 10 секунд на пользователя в каждом сервере отдельно).

Разрешённые источники задаются оператором через `.env` и администраторами сервера через `/settings sources`. Источник, которого нет в списке, не принимается, даже если его тип включён в `.env`.
